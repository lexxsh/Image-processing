## Included

- 주차별 C++/OpenCV 실습 코드
- 실습에 사용한 입력 이미지
- 주차별 보고서 PDF/DOCX
- 제출용 압축 파일

## Naming Rules

- 주차 폴더는 `week-XX-lab` 또는 `week-XX-lab-materials`로 통일했습니다.
- 보고서는 `report.pdf`, `report.docx`로 정리했습니다.
- 제출 압축 파일은 `submission.zip`으로 정리했습니다.
- 코드 파일은 `lab.cpp`, `task.cpp`, `tasks-*.cpp`, `ex-*.cpp`처럼 역할이 보이도록 정리했습니다.

## Notes

- 원본 저장소 설명에 따라 Visual Studio 2022 + C++ + OpenCV 기반 과제 모음으로 보관했습니다.
- 주차별 정확한 과제명은 보고서 원문을 열어야 더 정확히 맞출 수 있어서, README는 구조 중심으로 정리했습니다.
